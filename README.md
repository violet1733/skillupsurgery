# skill up surgery

外科手技のトレーニング記録およびランキング管理用ツールです。
ペグトランスファーをはじめとする外科手技のタイムを記録し、自己の成長を可視化（グラフ化）したり、チーム（先輩・後輩）でランキングを競い合ったりすることができます。

## 主な機能
- **タイム記録:** 分・秒単位での手技タイム記録
- **自己成長可視化:** 過去のタイム推移をグラフ（Chart.js）で確認
- **ランキング機能:** 誰が一番速いか、手技タイムのランキングを表示
- **履歴管理:** 全練習記録の一覧表示
- **ローカル保存:** ブラウザにデータを保存するため、ログイン不要で即座に使用可能

## 使い方
1. 本リポジトリの GitHub Pages にアクセスします。
2. ニックネーム（イニシャル等）を入力します。
3. 練習した日時とタイム（分・秒）を入力して「記録する」ボタンを押します。
4. グラフとランキングが自動的に更新されます。
